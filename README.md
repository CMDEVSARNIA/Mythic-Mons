# Mythic Mons

An 8-bit, top-down monster-collecting RPG in the spirit of Pokémon Emerald,
built with **Godot 4.7** and GDScript.

This is the foundation milestone: tile-locked movement, a multi-town world,
dialogue, field moves, wild-encounter triggers, and a soundtrack. All of it
runs with **no downloaded assets**. The art and chiptune music are generated
by code, and real assets slot in later without code changes.

## Quick start

1. Install [Godot 4.7](https://godotengine.org/download) (standard build, no .NET needed).
2. Open `project.godot` in Godot and press **F5**.

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | Arrows / WASD | D-pad / left stick |
| Run (hold) | Shift or X | B |
| Talk / confirm (A) | Z or Space | A |
| Cancel (B) | X or Backspace | B |
| Start menu | Enter or Esc | Start |

## What's in the prototype

- **Emberfall Town.** Your house (door → interior → exit mat), a sign, NPCs,
  and a secret garden behind a **CUT** tree.
- **Route 1.** Tall grass with wild encounters, one-way **ledges**, and a
  hiker trapped behind a **ROCK SMASH** boulder.
- **Tidewater City.** A beach and an island you reach with **SURF**.
- **FLY** from the start menu (Enter) to any town you've visited.
- Emerald-style feel: tap to turn in place, hold to walk, bump into walls,
  run at double speed, location banner on entering a map, typewriter text box.
- Wild encounters flash the screen and show the generated monster. The battle
  system is the next milestone.

## Project layout

```
autoload/      Events (signal bus), GameState, Audio
scenes/        main/, actors/ (GridActor, player, npc), maps/, objects/, ui/
scripts/       core/ (Grid, PhysicsLayers, Terrain), art/ (PixelArt), audio/ (ChipSynth, Chiptune, Songs)
assets/        placeholder/ (generated PNGs), tilesets/, ui/, fonts/, audio/
tools/         Headless generators for the art, TileSet and starter maps
tests/         Smoke test that plays the game
docs/          ARCHITECTURE.md, ASSETS.md
```

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): directory tree, node setups,
  physics layers, how grid movement and field moves work, adding maps.
- [docs/ASSETS.md](docs/ASSETS.md): what's generated, how to replace it, and
  free CC0 sources for tiles, sprites, monsters, SFX and music.

## Generated content

```sh
# Regenerate placeholder art; keeps the TileSet/maps you've edited
tools/rebuild_placeholders.sh
# Also rebuild the TileSet and the four starter maps from tools/build_world.gd
tools/rebuild_placeholders.sh --force
```

Set `GODOT=/path/to/godot` if the binary isn't on your `PATH`. Sound needs no
build step: `Audio` synthesizes it at startup on a worker thread. Any file in
`assets/audio/` with a matching name replaces the generated sound.

## Tests

```sh
godot --headless --path . --fixed-fps 60 --script res://tests/smoke_test.gd
```

This plays through the prototype by injecting input and checks 23 behaviors.
Run it without `--headless` to also save screenshots to
`user://screenshots/`.

## Roadmap

1. **Monster data.** `MonsterSpecies` resources (stats, types, learnsets,
   unique abilities) and `Monster` instances (level, EXP, moves, IVs).
2. **Battles.** A turn-based battle scene: Fight / Bag / Monsters / Run,
   type chart, ability hooks (`on_switch_in`, `on_hit`, …), catching with
   capture odds.
3. **Party & menus.** Party screen, bag, monster summary, save/load
   (`GameState` → JSON in `user://`).
4. **Field-move gating.** Unlock CUT/SURF/FLY through party moves and badges
   instead of the prototype's all-unlocked default.
5. **Content.** Trainers with line-of-sight battles, a Monster Center, a mart,
   more routes and towns, and real art from the sources in ASSETS.md.
